# 🍰 SD Bem Casados

> **Mais que um doce, um gesto de carinho.**

Site institucional desenvolvido para a **SD Bem Casados**, marca especializada em bem-casados artesanais para casamentos, eventos, aniversários e ocasiões especiais.

O projeto foi desenvolvido com foco em uma experiência visual sofisticada, navegação intuitiva, apresentação dos produtos e facilidade de contato para encomendas.

---

## 🌐 Demonstração

🔗 **Site:** https://jmmdm6.github.io/bem-casado/

📱 O projeto também foi desenvolvido com **design responsivo**, adaptando a experiência para computadores, tablets e celulares.

---

## ✨ Sobre o projeto

O site apresenta a identidade visual da SD Bem Casados e reúne informações sobre seus produtos, eventos e formas de contato.

Entre os principais objetivos estão:

* Apresentar a marca de forma profissional;
* Exibir os produtos e suas características;
* Mostrar trabalhos realizados em diferentes tipos de eventos;
* Facilitar o contato para informações e encomendas;
* Criar uma experiência visual elegante e agradável;
* Adaptar o site para diferentes tamanhos de tela.

## 💎 Diferenciais apresentados

O site destaca alguns dos principais diferenciais da SD Bem Casados:

**Tamanho acima do padrão**
Bem-casados maiores, pensados para proporcionar uma experiência ainda mais especial.

**Recheio generoso e cremoso**
Recheios preparados para proporcionar sabor e textura em cada mordida.

**Embalagem personalizada**
Embalagens desenvolvidas de acordo com a identidade e proposta de cada evento.

**Atendimento**
Atendimento próximo e personalizado durante o processo de encomenda.
